The creator replied to a request to download and use the animation as a wallpaper: “Definitely! Totally free to use for any purpose!” The creator then supplied the original download link above.

`emberblend-cherry-blossoms.mp4` is a silent, 1920×1080 H.264 copy of the creator's one-minute video, prepared for browser playback. Its composition, timing, and color are retained; audio is removed. `emberblend-cherry-blossoms.webp` is a preview frame from that copy. ArtDrops claims no authorship of the artwork.

The original downloadable file is 3840×2160 HEVC. According to the creator, the animation was rendered at 540p and upscaled with Topaz Labs Video Enhance AI. It is not native 4K footage.
